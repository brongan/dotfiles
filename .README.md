# Brennan's dotfiles

GNU Stow packages for an Arch Linux/Wayland workstation. Each top-level
directory mirrors paths below `$HOME`; install all packages with:

```sh
stow --no-folding */
```

To install only selected configurations, name them explicitly, for example:

```sh
stow --no-folding zsh git nvim tmux
```

## Dependencies

Only install the dependencies for the packages you stow. Package names below
are the executable or common Arch package names; some are available from the
AUR rather than the official repositories.

### Bootstrap

- `git`
- `stow`

### Shell and terminal

- `zsh`
- `atuin`, `direnv`, `fzf`, `zoxide`, and `starship` for optional shell hooks
- `bat`, `btop`, `eza`, `fd`, `git-delta`, `tree`, and `viddy` for aliases,
  previews, and pager integration
- `zsh-autosuggestions` and `zsh-syntax-highlighting`
- `ghostty`, `kitty`, `tmux`, and `zellij` for their respective configs
- `tmux-plugin-manager` for the tmux plugin loader
- `ttf-firacode-nerd` (a copy is also included under `fonts/`) for icons and
  terminal glyphs

### Editors and development tools

- `neovim`, plus `git`, `curl`, a C compiler, and `make` for the configured
  plugin manager and native plugins
- `ripgrep` and `fd` for Telescope
- language servers enabled by Neovim: `bash-language-server`, `clangd`, `gopls`,
  `lua-language-server`, `pyright`, `rust-analyzer`, `taplo`,
  `typescript-language-server`, and `wgsl-analyzer`
- formatters used by Neovim: `alejandra` or `nixfmt`, `dprint`, `ruff`,
  `rustfmt`, `shfmt`, `stylua`, and `taplo`
- `bazel`, `bear`, `clang`, and a JDK for the Bazel shell alias/config
- `jj` (Jujutsu), `nix`, `npm`, `paru`, and Python's `black` and `flake8` for
  their respective configs

### Wayland desktop

- `hyprland`, `hypridle`, `hyprlock`, and `hyprshot`
- `fuzzel`, `ironbar`, `dunst`, `wlogout`, and `swaybg`
- `pipewire`, `pipewire-pulse`, `wireplumber`, `pavucontrol`, `pamixer`, and
  `playerctl`
- `brightnessctl`, `cliphist`, `wl-clipboard`, `libcanberra`, and `xsettingsd`
- `blueberry`, `kdeconnect`, `libinput-gestures`, and `polkit-gnome`
- optional applications referenced by startup rules or key bindings: `firefox`,
  `signal-desktop`, `vesktop`, `thunar`, `obsidian`, `steam`, `sunshine`, and
  `passage`/`passage-gui`

### Standalone configured applications

- `bat`, `cava`, `chromium`, `fuzzel`, `ghostty`, `ironbar`, `kitty`, `spotifyd`,
  `tiny`, and `wlogout`
- `opencode` for `llama/.config/opencode`; `llama.cpp` (providing
  `llama-server`) for the accompanying user service

### Optional scripts and user services

- `ffmpeg` with VA-API support for `webcam-stream@.service`
- `systemd` user services for KDE Connect, libinput gestures, webcam streaming,
  and llama-server

Several configs are hardware- or host-specific: Hyprland expects an untracked
`~/.config/hypr/monitors.conf`, and the battery script uses `BAT1`. Review those
before use.
